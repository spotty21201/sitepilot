# Product Gaps and Next Phase

The following product and submission improvements are intentionally deferred. They do not invalidate the current release baseline. The accepted Spatial Console design and canonical deterministic geometry architecture should be preserved while this work proceeds.

1. Implement a persisted Taskmaster investigation agent with a structured Gemini-generated plan, automatic read-only investigation tools, auditable run history, approval before canonical mutations, stale-revision protection, and a resumable completion report.
2. Strengthen the first-time journey from opportunity intake to the Decision Room.
3. Add real geographic context: Google Maps or equivalent base context, cadastral/lot-line import, coordinate and north provenance, surrounding roads/buildings, and explicit context-verification status.
4. Improve progressive disclosure and first-time-user guidance without redesigning the accepted Spatial Console.
5. Validate provenance, planning assumptions, and conclusions using additional real professional cases.
6. Replace browser-only persistence with an appropriate account-backed, shareable, and auditable application architecture in a later full-app phase.
7. Complete hackathon submission work only after the agentic vertical slice, hosted Google Cloud proof, owner attestations, licensing decision, and demonstration video are complete.

SitePilot must not yet be described as a formally compliant or autonomous-agent submission. See [`docs/HACKATHON_COMPLIANCE.md`](HACKATHON_COMPLIANCE.md) for the authoritative submission status.
